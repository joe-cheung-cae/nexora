# Code of Conduct

Treat contributors with respect. Give constructive feedback, focus disagreements on the work, and welcome people of all backgrounds and experience levels. Harassment, threats, discriminatory language, and sharing someone's private information without consent violate this code.

This code applies to Nexora project spaces, including issues, pull requests, and code reviews. Maintainers may remove violating content or restrict participation.

Report incidents privately using the [maintainer's published contact details](https://github.com/joe-cheung-cae#contact). For abuse on GitHub, you can also use [GitHub's reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
