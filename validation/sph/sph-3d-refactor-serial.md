## M1 EOS 与固定壁采样

Tait EOS、Adami 外推和固定壁运动学进入方法目标。压力共享同一对称力核，普通 ghost 按自身支撑域重构。新增 `nexora_sph_tests.SphAdamiWall.WallPressureAndForcesMatchIndependentReference`，逐输入独立对照 double 壁压、窄化后系数、流体表压及加速度。依赖守卫和安装消费限制新私有头。

Serial 验证器在禁网环境执行。Debug float 在 2026-11-24T14:30:00+08:00 完成，常规 CTest 133/133，搬迁消费 1/1，三维发现 60 项。Release double 在 2026-11-24T14:29:44+08:00 完成，常规 CTest 131/131，搬迁消费 1/1，三维发现 59 项。两组一维均 7/7，依赖检查和 Reference Decimal oracle 均通过。Release double 的 6³ 轨迹复现三份完整 CSV 及 `steps.csv` 的所有数值列，受控字节逐步增加 23,360 B，对应 584 个固定壁记录各 40 B。

独立审查在 Release double 另跑 20 项 Adami、压力与连续性用例，未发现需修复问题。单独删去异 ID 重合流体的 `W(0)` 后，新用例在两份输入均检出壁压、系数和加速度误差。恢复原实现复测通过。验证器与审查日志位于本机 `results/sph-refactor-execution/m1/`。

## M2 查询视图与格网准入

密度、压力、连续性与 Adami 共用同阶段的只读邻域查询。格网在分配前分别预留排序字段、索引、探测排列及排序键。按 ID 的版本比较先预留两张 scratch 表。独立 CSR、显式回调原序、等质量与不等质量解析场和受控分配事件都进入回归。

合并 M1 与 M2 后两组依赖守卫均通过。Debug float 执行一维 7/7、三维 66/66，于 2026-11-24T14:35:41+08:00 完成。Release double 执行一维 7/7、三维 65/65，于 2026-11-24T14:35:28+08:00 完成。六项新增格网用例的完整名称均登记于 Serial 验证器。反转记录顺序的隔离负对照命中断言。八粒子重排仅余 63 B 时两张表均未分配，成功重建与比较的受控峰值为 float 880 B、double 1,136 B。

独立审查发现格网和查询默认赋值可能先释放旧票据，已改为交换整组所有权，逐条释放回调核实受控额度。合并预检发现压力反表仍引用旧格网类型，已接到查询索引型别，并补齐移除间接包含后的显式依赖。独立 Release double 复验通过 42 项相关用例。发现清单、两个配置的执行记录、审查复验及负对照位于本机 `results/sph-refactor-execution/m2/`。

## M3 步进、几何与同步读取

`WcsphStep3D` 持有派生格网及六个积分缓冲，`WcsphParticipant3D` 持有输入槽几何、受控行表、四字段和窗口。初始化与试算在建格后按同一行序签发写授权。读口同步复制粒子值，格网驱逐后按输入槽重建并核对源映射和 owned 行序。独立全扫描覆盖两端速度、邻居、密度率、半踢、校正和终踢，跨格发布和撤销后与直接运行逐行比较。
