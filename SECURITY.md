# Security Policy

Nexora is in early development. Reports are most useful when they identify the affected commit and whether the issue also occurs on the current default branch.

Use the private reporting form on [GitHub Security Advisories](https://github.com/joe-cheung-cae/nexora/security/advisories) when available. Otherwise, use the [maintainer's published contact details](https://github.com/joe-cheung-cae#contact). Keep vulnerability details private while the report is being reviewed.

Include the affected component, version or commit, build configuration, steps to reproduce, and expected security impact.
